# App screens prototype

Live: https://ottsme.github.io/time_machine/screens/

Static mockups of the screens around the trip (route, destination, save a place, settings, journey complete), themed like the HUD (`hud/`) and the story menu (`menu/`): dark ground, glass bars, console keys, one console light for state, the signature red only for starting a journey.

Nothing is clickable. Place names are examples; the arrival picture is a drawn stand-in.
